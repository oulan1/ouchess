# ouChess

Постоянный портал и PWA-точка входа для тактической 1v1 арены **ouChess** (режимы **Обычный 9×9** и **Турбо 7×7**).

- Когда хост запущен через локальную панель управления, портал автоматически перенаправляет игроков на актуальный публичный шлюз.
- Когда хост остановлен, страница отображает статус технического обслуживания и автоматически ожидает запуска сервера.
- Поддерживает установку как **PWA-приложение** на рабочий стол и мобильные устройства.
